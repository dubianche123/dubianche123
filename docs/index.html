AXIOM Drive Backup

Personal backups, managed on your own computer.
在本人电脑上管理的个人备份工具。

用途与工作方式

AXIOM Drive Backup 是供个人使用的本机备份配置，使用 restic 和 rclone，将本人选择的本地数据备份到本人的 Google Drive。它不提供公众注册服务，也没有接收备份内容的自建服务器。

Google 授权仅使用 drive.file 权限，用于创建和管理本应用创建的备份文件；不读取 Google Drive 中与本应用无关的文件。restic 快照内的文件内容与路径在本机加密后上传。备份说明等运维文字可能在私人 Drive 中以明文保存。

备份由用户在本机发起和管理。本页介绍用途与数据处理方式，不表示某次备份已经完成，也不保证所有数据均可恢复。详细的数据保存、删除和撤销授权方式见隐私说明。

Purpose and operation

AXIOM Drive Backup is a personal backup setup that runs locally. It uses restic and rclone to back up selected local data to the user's own Google Drive. It is not a public registration service and has no self-operated server receiving backup contents.

Google authorization uses only the drive.file scope to create and manage backup files created by this application. It does not read unrelated files in Google Drive. File contents and paths within restic snapshots are encrypted locally before upload. Operational text, such as backup instructions, may be stored as plaintext in the user's private Drive.

The user initiates and manages backups on their own computer. This page describes the utility and its data practices; it does not certify completion of any backup or guarantee recovery of all data. Read the privacy notice for storage, deletion, and authorization controls.
