## 正在做什么

我正在构建 **Axiom Loom**：一个本地优先的 Agent 运行时，探索连续上下文、记忆与多 Agent 协作。

想法很简单：上下文窗口的大小应当是实现细节，而不是需要用户操心的事。

> **底层严谨，使用从容。**

## 精选项目

这些项目从不同尺度探索同一件事：让代码职责清晰、上下文组织有据可查，也让 Agent 的行为能够被检查。

| 项目 | 可以探索什么 |
|:--|:--|
| **[The Regular · 老群友](https://github.com/dubianche123/the-regular-qq-bot)** | 常驻 QQ 群的 AI 角色，由代码管理关系与滚动记忆，提供无需账号的离线演示。 |
| **[Neural-Janitor](https://github.com/dubianche123/neural-janitor-tab-manager)** | macOS 上的 Chrome、Edge 标签管理工具，通过本机 Swift companion 学习个人保留习惯，默认先预览再清理。 |
| **[Loop Warden](https://github.com/dubianche123/coding-agent-supervisor)** | 面向 Hermes 的 skill 与 Python helper，用明确的任务约定和结构化交接，有界委派本地 coding CLI。 |
| **[The Norn Machine](https://github.com/dubianche123/norn-context-engineering)** | 用图片选择演示确定性上下文编排：Python 构建行为档案，模型负责把档案表达成语言。 |
| **[AgenticX Decision](https://github.com/dubianche123/agenticx-document-review)** | 文档审查研究原型，结合有界检索、显式 Python 规则工具与可检查的证据。 |

## 我的工作方式

在权限和规则重要的地方，我倾向于使用确定性控制；能留在本地的个人数据尽量留在本地；架构也应当能够跨越单一模型供应商的生命周期。我喜欢有用的默认值，而不是堆满配置项，并尽量用测量支撑重要的判断。

因此，我常常在模型从演示走向可靠软件的交界处工作。
